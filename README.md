## 🌸 About

**My_Friend_Beauty_Shop** is a simple e-commerce website developed by **Temesgen** using React, Tailwind CSS, and TypeScript.

Customers can browse beauty products, choose their favorite items, and click the order button to be redirected automatically to the vendor's or merchant's Telegram account or bot to place their order.

## 🛍️ How It Works

| Step | Description |
|:---:|---|
| 🛒 01 | Visit the website |
| 💄 02 | Choose your favorite products |
| 📦 03 | Click the Order button |
| ✈️ 04 | Continue to the vendor's Telegram account or bot |
